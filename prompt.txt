PROMPT INTERACTION LOG – 2D GRAPHICS EDITOR PROJECT

======================================================
PROMPT 1
======================================================

Analyze the following C program for a menu-driven 2D Graphics Editor using structures, unions, enums, and a 2D character array. Explain the architecture and how each component works.

RESPONSE:

This C program implements a menu-driven 2D Graphics Editor that allows users to draw and manage geometric objects on a text-based canvas.

Program Architecture:

1. Constants
- ROWS = 30 → Canvas height
- COLS = 60 → Canvas width
- MAX = 100 → Maximum number of drawable objects

2. Enumeration
typedef enum{
LINE=1,
RECTANGLE,
CIRCLE,
TRIANGLE
} ObjectType;

Purpose:
Assigns a numeric identity to each shape.

3. Structures

Line:
Stores starting and ending coordinates.

Rectangle:
Stores opposite corners.

Circle:
Stores center coordinates and radius.

Triangle:
Stores three vertex coordinates.

4. Union

union{
Line line;
Rectangle rect;
Circle circle;
Triangle tri;
};

Purpose:
Only one shape exists in an object at a time, reducing memory usage.

5. Object Structure

typedef struct{
ObjectType type;

union{
Line line;
Rectangle rect;
Circle circle;
Triangle tri;
} data;

} Object;

Purpose:
Stores object type and its related data.

6. Canvas

char canvas[ROWS][COLS];

Purpose:
Acts as the drawing board.

Program Flow:

Initialize Canvas
↓

Display Menu
↓

Select Shape
↓

Store Object
↓

Render Shape
↓

Display Canvas

======================================================
PROMPT 3
======================================================

Explain the drawing algorithms used.

RESPONSE:

LINE DRAWING

Algorithm:
Bresenham Line Algorithm

Steps:
1. Compute dx and dy
2. Determine movement direction
3. Plot points until destination

Complexity:
O(max(dx,dy))


RECTANGLE DRAWING

Method:
Draw four connected lines.

Steps:
Top
Right
Bottom
Left

Complexity:
O(perimeter)


CIRCLE DRAWING

Algorithm:
Midpoint Circle Algorithm

Steps:
1. Start at (0,r)
2. Plot symmetrical points
3. Update decision parameter

Complexity:
O(r)


TRIANGLE DRAWING

Method:
Three connected line drawings.

Complexity:
Depends on side lengths.
